## 階段一：C 基礎＋第一次點亮 LED（第 1～4 週，2026/11）

| 週 | Beej（C 語言） | Samek（板子） | 動手做 |
|---|---|---|---|
| 1 | Ch3 收尾、Ch4 Functions | lesson 1～3（計數、變數、pointer 入門） | Mac 上把 Ch3 練習改成用 `scanf` 的選單 |
| 2 | Ch5 Pointers、Ch6 Arrays | lesson 4（直接寫 register 點亮 LED） | 用 `GPIOA->ODR` 點亮 LD2（PA5） |
| 3 | Ch7 Strings、Ch8 Structs | lesson 5～7（preprocessor、`volatile`、bitwise、array） | 讀懂 `stm32f401xe.h` 裡的 `GPIO_TypeDef` |
| 4 | Ch11 Pointers II、**Ch24 Bitwise** | lesson 8～10（function 與 stack） | 用 PC13 按鈕控制 LED（pull-up） |

```c
// 階段一的目標：能逐字解釋這幾行
RCC->AHB1ENR |= (1U << 0);        // 開啟 GPIOA 的 clock
GPIOA->MODER &= ~(3U << (5 * 2)); // 清掉 PA5 的 mode 欄位
GPIOA->MODER |=  (1U << (5 * 2)); // 把 PA5 設成 output
GPIOA->ODR   ^=  (1U << 5);       // 切換 LED 亮滅
```

:::warning
- Beej Ch9（File I/O）在 MCU 上幾乎用不到，可以先跳過。
- 不要用 HAL，只寫 register，這樣才會真正懂硬體。
:::

## 階段二：密碼鎖 v1、v2＋進階 C（第 5～10 週，2026/12～2027/01 中）

| Beej | Samek | 專案 |
|---|---|---|
| Ch12 `malloc`（MCU 上盡量避免使用）、Ch13 Scope | lesson 11～15（模組化、struct、CMSIS、**startup code、linker**） | **v1**：4x4 矩陣鍵盤＋LED＋蜂鳴器＋debounce |
| **Ch16 `const` / `volatile` / `static`**、Ch17 Multifile | lesson 16～20（**interrupt**、race condition） | 鍵盤改成用 interrupt 或 SysTick 輪詢 |
| Ch20 Structs II（bit field、union）、**Ch23 function pointer** | lesson 35 之後的 state machine 單元 | **v2**：先用 `switch`＋`enum` 寫 FSM，再改成 function pointer 表 |

- 同時開始用 Git，`progit.pdf` 讀 Ch1～3 就夠用。每個版本打一個 tag，推上 GitHub。
- **目標**：v1、v2 上傳 GitHub，README 記錄遇到的 bug 和解法。

## 階段三：周邊通訊（第 11～18 週，2027/01～03）

| 版本 | 主要查閱 | 考點 |
|---|---|---|
| **v3** OLED（I2C）＋舵機（PWM） | RM0368 的 I2C、TIM 章節 | I2C、Timer/PWM、MOSFET 驅動 |
| **v4** RFID（SPI）或指紋模組（UART） | RM0368 的 SPI、USART 章節，pm0214 的 NVIC | UART interrupt、**ring buffer** |
| **v5** 密碼存進 Flash，加上錯誤次數鎖定 | RM0368 的 Flash 章節、`.ld` linker script | memory layout、`const` / `static`、linker |

- 脫離 CubeIDE、自己寫 Makefile 時，搭配 `GNU_make_manual.pdf`。
